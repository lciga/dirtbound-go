# Автомобили

При добавлении или изменении модели автомобиля сначала прочитать `docs/vehicle-style.md` и использовать `web/js/CarStyle.js`. Собрать проверяемые проекции и размеры производителя, выделить признаки силуэта и сравнить их с существующим раллийным набором. Проверять перед, зад, бок и верх, общий бюджет с четырьмя колёсами, нормали, ливрею и реальные границы контакта со стенами. Сохранять эти правила для всех следующих моделей.

Обычная физика и экспериментальная трансмиссия разделены: менять поведение движения в бете, проверять численную совместимость обычного режима через `npm run test:parity`. Для беты проверять Go/WASM вместе с Vehicle и реальным Crashcat, а не только чистые формулы. Серверные изменения проверять на отдельной PostgreSQL; обновления схемы выполнять номерными миграциями без удаления пользовательских томов.

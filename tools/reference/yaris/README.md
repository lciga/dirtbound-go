# Одобренная Toyota GR Yaris

`approved.glb` — точный мастер-экспорт, принятый пользователем 3 ноября 2026 года. Он содержит UV-ливрею и отдельную маску свечения. После редактирования в 3D-редакторе новый мастер нужно вновь проверить и согласовать, затем обновить контрольную сумму в `manifest.json`.

`node tools/build-yaris.mjs` проверяет мастер и копирует его в игру. `recolor.py` (Python, Pillow, NumPy) создаёт четыре дополнительных цветовых варианта атласа. Рисунок персонажей сохраняется; первый, согласованный вариант берётся непосредственно из GLB.

`authoring.mjs.txt` и `paint-livery.py.txt` — снимки процедур адаптации и ливреи из отдельного предпросмотра; они сохранены для объяснения происхождения сетки и UV, не являются игровым сборочным скриптом. Источник исходной геометрии и лицензия — в `ATTRIBUTION.txt`. Проверки отдельного предпросмотра — в `validation.json`.
